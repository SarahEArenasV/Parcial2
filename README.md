# Parcial 2 - Programación II

Sistema backend por consola de la plataforma de comercio electrónico **ShopMaster**, implementado en Java con los 5 patrones de diseño estructurales.

## Patrones implementados
| Requerimiento | Patrón | Paquete |
|---|---|---|
| Gestión de productos y combos | Composite | `composite` |
| Servicios opcionales del pedido | Decorator | `decorator` |
| Integración con pasarela StripeUSA | Adapter | `adapter` |
| Seguridad, control de cupos y auditoría | Proxy | `proxy` |
| Compra rápida (One-Click Checkout) | Facade | `facade` |
